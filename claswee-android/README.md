# claswee 安卓测试版

独立 Android 客户端，使用 Vue 3 + Capacitor 8。界面与脚本打包进 APK，在设备上离线运行；未加载远程网页。0.1.3 与微信小程序统一保留课程右下角的小猫爪印和小狗骨头，填写教室或老师后仍显示，单节卡片最后一行预留角标空间；分享图（含打码）同步修复。生产后端未修改。

0.1.1 按现有小程序源码恢复界面。`src/mini/` 的六个页面、底部导航、小纸条及皮肤直接从 `couple-schedule-v41/miniprogram` 转换；保留原来的布局、颜色、rpx 尺寸、课程定位算法、文字与图形背景。底部固定为“设置 / 课表 / 同步”，中间课表图标抬起，小纸条从同步页打开。

必要的平台适配包括安卓状态栏和手势区域、系统相册/文件选择与分享、将微信资料选择改为相册和昵称输入，以及设置页增加隐私与云服务入口。没有模拟微信专属胶囊按钮。`artifacts/mini-ui-source-map.json` 记录每个被复用文件的 SHA256；用 `node tools/port-mini-ui.mjs` 可重新转换，安卓专用控制器不受覆盖。

## 已实现

- 双人周课表及每日时间表，共同空闲时间。
- 新增、编辑、删除课程，多时段、单双周、自定义周次。
- 两个人独立开学日期、节次、昵称和头像；本机身份与皮肤不被对方覆盖。
- 创建、加入、退出房间及修改密码，兼容当前小程序的房间协议。
- 原版小纸条弹窗、发送、收好与本机保存；失败重试保留幂等编号。
- 课表图片识别、逐项编辑确认后导入，复用现有识别接口。
- JSON 备份导出、分享与恢复，兼容现有课表结构。
- 原版周课表分享图，真实小程序码、包含周末和柔光打码选项；保存图片与系统分享。
- 四套皮肤，首次隐私选择，纯本地模式。

## 数据与连接

课表及修改队列保存在应用私有 SharedPreferences 中。房间连接由 Android Keystore 的 AES-GCM 密钥加密，写入私有 SharedPreferences；凭证不会写入日志或课表备份。应用禁止系统云备份和设备迁移自动复制这些记录，换机请主动导出课表并重新加入房间。

网络错误、休眠、服务器超时不删除房间、令牌或设备标识。明确的凭证失效只标记为需要重新验证；重新加入同一房间会合并未同步的本机编辑。回到前台立即同步，前台每15秒检查，后台不维持轮询。

同步使用拉取后合并再上传，按课程ID、删除标记和字段差异合并本机尚未提交的修改。双方同时修改同一字段仍可能需要人工核对，建议定期导出备份。

## 构建

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run android:build
```

构建脚本使用 `D:\codex-tools\claswee-android` 下的便携 JDK 21、Android SDK 36 和 Gradle 8.14.3，不改机器全局 Java 设置。正式开发也可在 Android Studio 中打开 `android/`。

产物：`artifacts/claswee-android-0.1.3.apk`。版本码4，可覆盖同一开发签名的0.1.0/0.1.1/0.1.2。当前使用 Android debug 签名用于内部安装，不能直接作为应用商店正式发布包。最低 Android 7.0（API 24），目标 Android 16（API 36）。不适用于仅支持鸿蒙原生应用的设备。

正式签名构建可运行 `npm.cmd run android:release`。请先设置本机签名身份并妥善保存签名材料。运行 `node tools/verify-release.mjs --release` 可核对候选包的签名和版本。

## 验证

- `npm.cmd test`：不同开学日期、共同空闲时间、双人同时编辑、删除合并、凭证保留、输入校验。
- `tests/smoke.mjs`：对照小程序原始算法检查课程位置、网格高度、七天横向滚动、三栏导航、四套配色和2×2预览；课程、身份、昵称、头像、周一日期及皮肤持久化；分享图离线生成；320/390/430px视口与安全区域；本地模式无外部请求。
- `tests/pair-sync.mjs`：两台隔离客户端连接模拟服务，验证同步、纸条、断网和失效凭证恢复。不会发送真实小纸条或修改生产用户数据。
- `artifacts/` 保存验证结果和界面截图。

## 正式上架前仍需完成

真实 Android 手机上的安装、系统选择器、保存图片、系统分享、Keystore持久性及切后台测试；双机连接真实测试房间的验收。当前ADB没有连接手机，截图来自移动视口的浏览器验证，不能代替手机实测。

当前没有后台推送、支付或会员系统；小纸条在应用打开时同步。微信cloud://与wxfile://格式的旧头像不能直接在App中加载，请在设置中重新选择；系统表情字形也可能因设备字体略有差异。Android10及以上保存到Pictures/claswee，更老版本通过系统保存文件对话框选择位置，不申请整个相册访问权限。当前是内部测试版，独立release签名已经完成；正式上架前还需要运营主体、备案、版权证明、客服、最终隐私政策、云端数据删除流程、用户内容治理及真实设备验收。
