用户原句“数学课前五周单周，之后每周上”在20周学期内对应第1、3、5、6—20周；再说“第八周停一次”，仅排除第8周。信息缺失、周次越界或分界含糊时阻止保存并追问。单次模型JSON异常可在52秒总请求时间内修正一次，修正前不应用任何草稿操作；长批次输出不完整仍自动分段。

例如：`给小猫加高数：周一下午第一节，A302；英语：周三第3到4节，B201；给小狗加体育：周五下午第二节，操场。以上都是1到16周。` 支持一门或多门课程，无固定门数上限。信息不全的课程保留在列表中，支持按课程名、第N门或“全部”补充待确认草稿。不修改或删除已保存课程。

AI 只提取草稿；节次换算、周次与日期检查、与已有课程及本批课程之间的冲突和重复检查均由小程序执行。可单独勾选，用户确认后通过一次 Store.save 保存所有已选有效课程，同步沿用现有房间机制。撤销处理上次保存的整批课程；任一课程已被修改或删除则保留全部数据、提示人工核对。删除记录不按100条裁剪，以保证大批撤销后不会被旧同步数据恢复。

输入框不按字数截断。长文本按内容分段，模型输出截断或明确未完成时自动继续拆分；分段容量属于技术窗口，不限制草稿总门数。各段的明确公共条件会沿用；网络失败保留已生成草稿及未完成队列，继续处理时不会重复加入已完成段。未完成段存在时禁止确认保存。模型仍可能理解有误，保存前应核对完整性。

## 服务与身份

环境 `masic-blog-d6g6d4r87bc035c0e`，函数 `scheduleCourseAssistant`，Nodejs20.19，60 秒，256MB。HTTPS 路由 `/schedule-course-assistant` 与现有同步、截图导入共用已配置的 request 域名。该环境无法通过本小程序的原生 wx.cloud.callFunction 访问，实际调用使用 wx.request。

服务校验 Authorization 中的现有房间令牌哈希、有效期与房间归属；身份由数据库会话的房间与 client_hash 组成，不接受客户端自行声明身份。配额以身份哈希记录，每房间设备每天 20 次AI请求、全局每天 500 次请求，3 秒间隔及 70 秒请求锁；北京时间日切。一次请求可整理多门课程，配额不是课程门数限制。长文本分段及自动拆分会消耗多次请求；用量不足时保留草稿和待处理内容。存储或配额服务故障时不会调用付费模型。

环境变量：`DEEPSEEK_API_KEY`、`CLASWEE_DB_KEY`、`COURSE_ASSISTANT_MODEL=deepseek-flash`、`CLASWEE_COURSE_AI_VERSION=20261107-v1`。密钥只保存在服务端，不应写入客户端、报告或日志。

首次发送征求数据用途同意。只向 DeepSeek 发送本页课程描述与相关对话、待确认草稿、当前身份、昵称、学期和节次设置及上批保存/撤销的状态与门数；不发送已保存课程、头像、小纸条或房间凭证。服务不持久化对话；客户端会话保存在本机，点“开始新一批”可清空本批对话和草稿。
